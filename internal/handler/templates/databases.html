Managed databases

Run shared database containers for the whole server. Create Postgres, MariaDB, or MySQL databases, manage users, and connect from your applications.

View documentation

You can enable this feature at any time. It starts the shared Postgres container; MariaDB and MySQL start when you create their first database.

Create multiple databases

Spin up as many databases as you need for different projects or applications, on Postgres, MariaDB, or MySQL.

Manage users & credentials

Create and manage database users, set permissions, and rotate credentials with ease.

One shared container per engine

A single, reliable container for each database engine at the server level, started when you first need it.
