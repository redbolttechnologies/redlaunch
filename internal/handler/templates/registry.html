Purge older image versions?

Remove older versions from all repositories using each repository’s retention setting. The registry will be read-only during the operation; pushes and uploads fail until it finishes. Pulls remain available except during brief restarts. Deployed and running images are always kept. Application deployments are paused while maintenance runs.

{{if .RegistryPage.PurgeVersionCount}}

Up to {{.RegistryPage.PurgeVersionCount}} older {{if eq .RegistryPage.PurgeVersionCount 1}}version{{else}}versions{{end}} across {{.RegistryPage.PurgeRepositoryCount}} {{if eq .RegistryPage.PurgeRepositoryCount 1}}repository{{else}}repositories{{end}} will be removed.

{{else}}

No older tagged versions are current candidates. Retained untagged versions may still be removed.

{{end}}

Run garbage collection?

Unused image data will be removed permanently. The registry will restart in read-only mode: pulls remain available except during brief restarts, but pushes and uploads fail until collection finishes. Application deployments are paused while maintenance runs.
